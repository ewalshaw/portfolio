# portfolio-ewalshaw

Personal portfolio site for Erin Walshaw.
Available at [erinwalshaw.vercel.app](https://erinwalshaw.vercel.app).

## Tech stack

- **React** (UI)
- **Vite** (build tool)
- **Tailwind CSS** (styling)
- **Framer Motion** (animations)
- **React Router** (routing)
- **Lucide React** (icons)
